# JANUS — Scientific Intelligence Core

**Discriminative Experiment Selection for Competing Scientific Hypotheses**  
*Open Scientific Intelligence (OSI) Hackathon Project*

---

## Mission & Purpose

JANUS is a scientific intelligence system engineered to identify high-yield candidate experiments capable of distinguishing between rival scientific hypotheses.

Unlike generative LLMs that predict unstructured properties or summarize papers, JANUS implements a **deterministic, information-theoretic scoring engine** based on Shannon entropy and expected mutual information $I(H; Y)$:

$$EIG(e) = H(H) - \mathbb{E}_{y \sim P(y \mid e)} \left[ H(H \mid y, e) \right]$$

### Key Design Principles:
1. **Mathematical Determinism:** Scoring and ranking are strictly computed via probability calculus—no stochastic LLM decides the winning experiment.
2. **Explicit Uncertainty & Constraints:** Accounts for physical feasibility, technical limits, and resource cost.
3. **Data Provenance Integrity:** Differentiates clearly between synthetic benchmark values, user-supplied priors, and verified empirical observations.
4. **Baseline Evaluation:** Evaluates experiment rankings against naive alternatives (e.g., uniform random selection), proving tangible information-gain multipliers.

## Local Setup & Quick Start

### Prerequisites
- Python 3.12 (x64)
- Node.js 24+ and npm
- Windows PowerShell

### 1. Python Backend Setup

```powershell

# Activate virtual environment (already initialized)
```

## Verifiable Features in the Vertical Slice

- **Health Check & Diagnostic:** Real-time query to `/api/health` displaying engine operational status.
- **Demonstration Scenario:** Ingestion of a 3-hypothesis kinase signaling disambiguation benchmark.
- **Interactive Sensitivity:** Adjust prior probabilities $P(H_k)$ using sliders to observe dynamic Bayesian re-ranking.
- **Bayesian Posterior Matrix:** Inspect full $P(H_k \mid y)$ tables for each observable outcome.
- **Audit Log:** Complete step-by-step mathematical trace generated by `ScientificEngine` for every run.
- **Baseline Comparison:** Direct benchmark calculation comparing top candidate against uniform random selection policy.
