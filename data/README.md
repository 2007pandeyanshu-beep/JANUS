# JANUS Data Directory

This directory stores ground-truth datasets, benchmark fixtures, and scientific literature citations.

## Data Provenance Policy
1. **Synthetic Fixtures (`synthetic_fixture`):** Generated illustrative data for mathematical validation. Must never be presented as empirical results.
2. **User-Supplied Inputs (`user_supplied`):** Custom scientific scenarios input via the API or UI.
3. **Verified Empirical Observations (`empirical_observation`):** Literature-backed or lab-verified datasets with DOI/PubMed citations.
